# KeLin Cosmetics: приглашение на открытие

Статический сайт без сборки: открывается двойным щелчком по `index.html`. Шрифты Jost и Sacramento лежат в `assets/fonts/` вместе с лицензиями OFL: загрузка приглашения не зависит от Google Fonts.

Для разработки из корня репозитория: `python -m http.server 4173`. Параметры `?skip&lang=ru` пропускают двери и включают русский; без параметров основной язык — узбекский.

## Что где лежит
- `index.html`: разметка и все блоки страницы.
- `styles.css`: оформление, заставка с дверями, адаптив (проверено на 320, 375, 768, 1280 px).
- `app.js`: язык, заставка, нить истории, галерея со свайпом и стрелками, таймер, ссылки на карту, календарь, форма.
- `petals.js`: падающие лепестки.
- `config.js`: **всё, что меняется без правки кода**: дата, адрес, ссылки, фото и видео, адрес приёма ответов.
- `i18n.js`: все тексты на узбекском и русском (узбекский ждёт проверки носителем).
- `assets/logo/`: слои логотипа (ключ, Ke, Lin, COSMETICS) с прозрачным фоном. Вырезаны из PNG, потому что в `frame 251.svg` внутри картинка, а не вектор.
- `assets/petals/`: уголки с лепестками из фирменного борда.

## Как добавить фото и видео
Положите файл в `assets/photos/` и впишите путь в `config.js`, раздел `media`. Номера рамок: `hero-zuhra`, `hero-fotima` (портреты на первом экране), `story-1a`, `story-1b`, `story-2`, `story-3a`, `story-3b`, `story-4`, `gallery-1` … `gallery-5` (в `gallery-3` и `gallery-5` по умолчанию видео).

## Что ещё нужно перед публикацией
- Настоящие дата, время и адрес в `config.js`. Сейчас стоят примерные (15 ноября 2026, 18:00).
- В `config.js` поставить `sample: false`, чтобы убрать плашку «Демо-версия».
- Приём ответов гостей: форма работает, но отправка выключена (`rsvpEndpoint` пуст). Нужен Cloudflare Worker, который пересылает ответ в Telegram. Токен бота хранится только в Worker, не в коде страницы.
  До подключения адреса перед формой и на экране результата явно указано, что ответ не отправляется.
- Сайт выложен на GitHub Pages: https://shakhzodmir.github.io/keylin/ . Если переедет на свой домен, поменять `og:url` и `og:image` в `index.html`: для превью в Telegram и Instagram нужен полный адрес.
- Тексты истории сестёр: сейчас черновик, заменить настоящими воспоминаниями.
