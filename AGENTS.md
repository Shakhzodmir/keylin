# Для помощников (Claude, ChatGPT): читать перед работой

Проект: сайт-приглашение на открытие магазина корейской косметики **KeLin Cosmetics** (Ташкент). Владелицы: сёстры-близняшки Зухра и Фотима. Это отдельный проект, к приложению «Korean with Madie» отношения не имеет.

## Жёсткие правила
- Только HTML, CSS и чистый JS. Без фреймворков и без сборки. Статический сайт на GitHub Pages: https://shakhzodmir.github.io/keylin/
- **Репозиторий публичный.** Никаких токенов, ключей, паролей, личных номеров и e-mail в коде и коммитах. Приём ответов гостей (`rsvpEndpoint`) делается через Cloudflare Worker (код в `worker/`, инструкция в `worker/README.md`, тесты: `cd worker && node --test`), секреты лежат только в нём.
- Тексты для гостей на узбекском (основной) и русском. Все строки живут в `i18n.js`, в разметку и `app.js` их не вписывать.
- Дата, адрес, ссылки, фото и видео меняются только в `config.js`.
- Мобильная версия важнее: проверять на 375 и 768 px. Анимации плавные, 200 до 300 мс для интерфейса, `ease-out`, учитывать `prefers-reduced-motion`.
- Не называть локальную переменную `t` и не затенять функцию `tr()`.

## Бренд
Цвета сняты с логотипа: золото `#FCBC0C`, коралл `#F87C78`, фон `#FDE6E4`, какао `#3A1E12`. Золото и коралл на светлом фоне не дают нужного контраста, поэтому они только для декора и крупных надписей. Текст всегда какао или `#5A2D14`. Шрифты: Jost и Sacramento (Sacramento без кириллицы, только для латиницы).

Логотип в `assets/logo/` вырезан из растровой картинки четырьмя слоями (ключ, Ke, Lin, COSMETICS). Настоящего вектора нет. Если появится, заменить слои, не меняя размеры холста.

Личные фото сестёр лежат в `assets/photos/` и уже подключены в `config.js` (портреты, детство, Корея, галерея). Правила: перед публикацией обрезать под рамку, удалять EXIF (там может быть геопозиция), закрывать печатные личные данные на дипломах и документах (полные имена, отчества). Подписи к фото: Зухру и Фотиму называть только там, где личность подтверждена дипломом или самими сёстрами. Тексты истории про Корею (обе сестры учились в корейских университетах) выведены из фото и ждут подтверждения владельцев.

Сгенерированные композиции в `assets/art/` — оформление, не фотографии настоящего ассортимента или магазина. Сохранять честные подписи и не подменять ими личные фото сестёр. Пути настраиваются в `config.js`.

## Главное решение по дизайну
Заставка: БЕЗ ДВЕРЕЙ. Владелец отверг двери (в том числе «шкаф» из рифлёного стекла с ручками): они выглядели как мебель, а не как открытие магазина. Сейчас: бумажный фон с лепестками и логотип, по нажатию ключ делает оборот, от него расходится золотое кольцо, из ключа вылетают лепестки, страница открывается внутри растущего круга света. Не возвращать двери и створки. Сохранять кнопку пропуска, Escape и запасной вариант с растворением. По последней просьбе владельца страница тоже должна быть динамичной: появления выбранных блоков при прокрутке, лёгкий параллакс, наклон рамок и перетаскивание галереи. Не перехватывать вертикальную прокрутку; при `prefers-reduced-motion` весь контент доступен без этих эффектов.

Карта должна быть встроенной и появляться без нажатия по заглушке. Координаты — из `config.js`, ссылки на Google и Yandex сохранять.

## Как проверять
Открыть `index.html` в браузере. Для быстрого пропуска заставки: `?skip`, для языка: `?lang=ru`. Перед пушем убедиться, что нет ошибок в консоли и горизонтальной прокрутки на 320, 375, 768, 1280 px.

## Как не мешать друг другу
- Перед работой: `git pull --rebase origin main`. Коммиты маленькие, по одной теме. Не переформатировать файлы целиком.
- Не править одновременно один и тот же файл: если сомневаетесь, спросите владельца, кто чем занят.
